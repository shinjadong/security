## July 2025 Release: New Attack Vectors, Campaign Visibility, and UI Upgrades

CalypsoAI's July 2025 release introduces new capabilities across its Inference platform, focusing on enhanced red-team attack vectors, improved user interface, and better campaign visibility features.

---

## Inference Red-Team Updates

### Style Injection Attack Vector
The release adds a novel jailbreak method to the Red-Team arsenal. This approach manipulates "formatting and writing style (e.g., 'use no punctuation,' 'five-word sentences only')" to encourage models to circumvent safety guidelines. The release includes over **10,500 new malicious prompts** designed to test model vulnerabilities.

### Terminology Adjustment
Monthly "prompt packs" have been rebranded as **"attack packs"** to better align with offensive security terminology and industry standards.

### Raw Data Table Improvements
Usability enhancements include:
- Enhanced filtering and sorting functionality
- Visual result counts before and after filtering
- Automatic loading of additional results during scrolling

### Campaign Management Enhancements
New visibility features allow users to:
- View dedicated campaign columns on the Reports page
- Click campaign names for quick navigation to specific campaigns
- Access campaign IDs and report names in raw data views

### Error Messaging
New "schedule error" category helps identify connection problems with target models or applications during scheduled campaign runs.

---

## Inference Defend Updates

### Custom Scanner Details
Users can now access detailed views of custom scanners, displaying scanner tags and full descriptions to understand scanner functionality and detection capabilities.

### Key Takeaways

- Style Injection: 포맷/글쓰기 스타일 조작을 통한 새로운 탈옥 기법
- 10,500개 이상의 새 악성 프롬프트 포함
- "prompt packs" -> "attack packs" 용어 변경 (공격적 보안 용어에 맞춤)
- 캠페인 관리 가시성 대폭 개선
- 커스텀 스캐너 상세 보기 기능 추가
