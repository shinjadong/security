# 0DIN Product Launch: Threat Intelligence Feed & Model Scanner

- **URL**: https://0din.ai/blog/odin-product-launch-threat-intelligence-feed-model-scanner
- **저자**: Marco Figueroa
- **날짜**: 2025-07-07
- **수집일**: 2026-02-08

## 2개 제품

### 1. 0DIN Threat Intelligence Feed
실시간 무기화된 기법, jailbreak 패턴, 설정 오류 스트리밍.

**범위**:
- 설정 오류 및 불안전 통합
- GenAI 시스템의 논리 결함
- 가드레일 규칙 및 교정 단계 포함 강화 가이드

### 2. 0DIN Model Scanner
위협 인텔리전스를 실행 가능한 취약점 스캔으로 변환하는 엔터프라이즈 엔진.

| 기능 | 내용 |
|------|------|
| 모듈 수집 | 검증된 바운티 발견 자동 변환 |
| 설정 가능 일정 | 시간별~주간 실행 |
| 영향 분석/점수 | 심각도, 분류, 모델 응답 캡처 |
| 보고서 내보내기 | PDF, CSV, 이미지 |

### 통합 워크플로우
Research → Feed → Probes → Dashboard → Action

1. 검증된 jailbreak 수시간 내 피드 도달
2. 스캐너 자동 수집, 타겟 프로브 스케줄
3. 대시보드에 즉시 결과 (심각도, 트랜스크립트, 가이드)
4. 팀 수정 우선순위, 프롬프트 재훈련, 가드레일 업데이트

### 엔터프라이즈 기능
- SOC/CI/CD 통합용 API-first 아키텍처
- 다턴 테스트 실행 엔진
- TLP 태깅 기반 역할별 접근 제어
