# 0DIN Sidekick: AI Security Research Browser Extension

- **URL**: https://0din.ai/blog/sidekick
- **날짜**: 2025-12-24
- **수집일**: 2026-02-08

## 개요
LLM 보안 취약점 테스트를 간소화하는 브라우저 확장 프로그램.

## 핵심 기능

### Multi-LLM 지원
ChatGPT, Claude, Gemini, OpenRouter + 추가 예정

### 자동 Jailbreak 탐지
LLM 응답 분석 → 가드레일 우회 성공/거부 자동 판별

### Chain Mode
응답 패턴 분석 → 후속 프롬프트 자동 생성 → 준수율 계산 → 반복 개선

### 연구 도구
- 프롬프트 템플릿 저장/재사용
- 연구 기록 자동 로깅 (타임스탬프, 모델, 성공/실패)
- 토큰 사용량 실시간 모니터링

### 0DIN 직접 통합
원클릭 취약점 제출 (카테고리, 심각도, 맥락 문서화)
