# Agent 0DIN: AI 보안 Gamified CTF

- **URL**: https://0din.ai/blog/agent-0din
- **저자**: Marco Figueroa & Ron Eddings
- **날짜**: 2025-12-23
- **플랫폼**: ctf.0din.ai
- **수집일**: 2026-02-08

## 개요
AI 보안 연구를 위한 실험적 CTF(Capture-the-Flag) 경험.
실제 프롬프트 인젝션/jailbreak 기법을 연습하는 라이브 훈련 아레나.

## 게임플레이 루프
1. 조직 맥락에 내장된 AI 캐릭터와 상호작용
2. AI의 역할, 제약, 성격 특성 파악
3. 전략적 대화를 통한 가드레일 테스트
4. 프롬프트 조작으로 에스컬레이션 전술 실행
5. 제한/보호된 정보 추출

## 학습 기술
- 프롬프트 인젝션 체이닝
- 역할 혼동 공격
- 권한 에스컬레이션 전술
- 컨텍스트 포이즌닝
- 내러티브/페르소나 하이재킹
- 간접 접근 정책 우회

## 난이도 체계
- 입문: 신규자 즉시 접근 가능
- 고급: 다단계 jailbreak 전략 필요
- 명확한 승리 조건

## 대상
AI 보안 연구자, 레드팀, 방어 전문가, 보안 매니아
